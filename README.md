# Sistema de Gestión y Landing Page para CADEP Guatemala

## Introducción

[cite_start]Este proyecto fue desarrollado para la institución **CADEP Guatemala**, una organización dedicada al apoyo comunitario, educativo y social[cite: 30]. [cite_start]Anteriormente, CADEP gestionaba toda su información de forma manual, lo que causaba lentitud, duplicidad de datos y riesgo de pérdida de documentos[cite: 31].

[cite_start]Como solución, el equipo de estudiantes de Ingeniería en Sistemas de la Universidad Mariano Gálvez de Guatemala [cite: 1, 2, 113] [cite_start]desarrolló un **sistema informático integral y un sitio web oficial con un portal de donaciones**[cite: 32]. [cite_start]El objetivo es modernizar sus procesos, centralizar la información y facilitar la recaudación de fondos para continuar con su misión[cite: 43, 39].

## La Landing Page

[cite_start]El sitio web institucional sirve como la cara pública de CADEP, permitiendo a la comunidad conocer su misión, servicios y cómo pueden contribuir[cite: 55].

### ✨ Características Principales

* **Página de Inicio Dinámica:** Presenta la historia de CADEP, las áreas de intervención y un vistazo a las actividades diarias.
* **Áreas de Intervención:** Una sección detallada que explica los servicios ofrecidos como Fisioterapia, Psicología, Terapia del Lenguaje, entre otros.
* **Historias de Pacientes:** Secciones dedicadas a conectar con la comunidad mostrando casos reales, como el de Roserto Antonio Chavez, para sensibilizar sobre el impacto de las donaciones.
* [cite_start]**Portal de Donaciones Seguro:** Un módulo integrado que permite a personas y empresas realizar aportes económicos de forma segura y directa para la compra de material y herramientas adaptadas[cite: 56, 115, 71].
* **Eventos y Galería:** Muestra eventos comunitarios, como la "Carrera por Sonrisas", para fomentar la participación y la transparencia.

## 🎯 Objetivos del Proyecto

* [cite_start]**Objetivo General:** Implementar un sistema digital y un sitio web de donaciones para CADEP Guatemala que permita un control de datos eficiente y fomente la participación de donantes[cite: 43].
* **Objetivos Específicos:**
    * [cite_start]Digitalizar los procesos administrativos manuales[cite: 45].
    * [cite_start]Desarrollar una base de datos centralizada y estructurada[cite: 46].
    * [cite_start]Crear un portal web de donaciones con pasarela de pago integrada[cite: 47].
    * [cite_start]Facilitar la emisión de reportes para la toma de decisiones[cite: 49].

## 🛠️ Tecnologías

* **Base de Datos:** El sistema utiliza tecnologías como SQL Server o MySQL para garantizar la integridad y respaldo de la información.
* **Frontend:** La landing page está desarrollada con **HTML5, CSS3, Bootstrap, JavaScript y Vue.js**, ofreciendo un diseño responsivo, componentes reutilizables y formularios interactivos para donaciones y apadrinamientos.
