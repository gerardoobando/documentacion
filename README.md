# Sistema de Gestión y Landing Page para CADEP Guatemala

## Introducción

Este proyecto fue desarrollado para la institución **CADEP Guatemala**, una organización dedicada al apoyo comunitario, educativo y social. Anteriormente, CADEP gestionaba toda su información de forma manual, lo que causaba lentitud, duplicidad de datos y riesgo de pérdida de documentos.

Como solución, el equipo de estudiantes de Ingeniería en Sistemas de la Universidad Mariano Gálvez de Guatemala [cite: 1, 2, 113] [cite_start]desarrolló un **sistema informático integral y un sitio web oficial con un portal de donaciones**. El objetivo es modernizar sus procesos, centralizar la información y facilitar la recaudación de fondos para continuar con su misión.

## La Landing Page

El sitio web institucional sirve como la cara pública de CADEP, permitiendo a la comunidad conocer su misión, servicios y cómo pueden contribuir.

### ✨ Características Principales

* **Página de Inicio Dinámica:** Presenta la historia de CADEP, las áreas de intervención y un vistazo a las actividades diarias.
* **Áreas de Intervención:** Una sección detallada que explica los servicios ofrecidos como Fisioterapia, Psicología, Terapia del Lenguaje, entre otros.
* **Historias de Pacientes:** Secciones dedicadas a conectar con la comunidad mostrando casos reales, como el de Roserto Antonio Chavez, para sensibilizar sobre el impacto de las donaciones.
* **Portal de Donaciones Seguro:** Un módulo integrado que permite a personas y empresas realizar aportes económicos de forma segura y directa para la compra de material y herramientas adaptadas.
* **Eventos y Galería:** Muestra eventos comunitarios, como la "Carrera por Sonrisas", para fomentar la participación y la transparencia.

## 🎯 Objetivos del Proyecto

* **Objetivo General:** Implementar un sistema digital y un sitio web de donaciones para CADEP Guatemala que permita un control de datos eficiente y fomente la participación de donantes.
* **Objetivos Específicos:**
    * Digitalizar los procesos administrativos manuales.
    * Desarrollar una base de datos centralizada y estructurada.
    * Crear un portal web de donaciones con pasarela de pago integrada.
    * Facilitar la emisión de reportes para la toma de decisiones.

## 🛠️ Tecnologías

* **Base de Datos:** El sistema utiliza tecnologías como SQL Server o MySQL para garantizar la integridad y respaldo de la información.
* **Frontend:** La landing page está desarrollada con **HTML5, CSS3, Bootstrap, JavaScript y Vue.js**, ofreciendo un diseño responsivo, componentes reutilizables y formularios interactivos para donaciones y apadrinamientos.
